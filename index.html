Tentang Halaman

Halaman ini merupakan landing page yang dibuat sebagai implementasi tugas CI/CD dan Cloud. Website ini menggunakan HTML dan CSS serta memanfaatkan GitHub Actions untuk menjalankan proses build dan deployment secara otomatis ke GitHub Pages.

  • CI (Continuous Integration): Proses otomatis untuk mengambil kode dan menyiapkan hasil build setiap ada perubahan.
  • CD (Continuous Deployment): Proses publikasi hasil build secara otomatis ke GitHub Pages.
